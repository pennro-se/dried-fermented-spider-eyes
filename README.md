# Dried Fermented Spider Eyes (Datapack)

## Summary

Slow and steady may win the race but what if you aren't in a race?

This datapack adds a variant of the fermented spider eye which can be fed to your Happy Ghast whilst riding it to gain a temporary speed boost, useful for traversal between work areas. Just be careful not to consume it yourself!



## Requirements

Minecraft Java Edition 26.3

## Installation

Make sure to install both the datapack and resource pack for proper functionality.

There are no non-standard requirements for this datapack, follow the normal steps in Minecraft or your launcher of choice to add it to your world.

## Uninstallation

There are no non-standard requirements for this datapack, it can be removed or disabled at any time.

Note: Make sure no Happy Ghasts are currently under the effect of this datapack before removing or they will be sped up indefinitely.
