# Dried Fermented Spider Eyes (Datapack)

## Summary

Slow and steady may win the race but what if you aren't in a race?

This datapack adds a variant of the fermented spider eye which can be fed to your Happy Ghast whilst riding it to gain a temporary speed boost, useful for traversal between work areas. Be careful not to consume it yourself!

## Usage

Just dry out a Fermented Spider Eye with a furnance, smoker, or campfire to get a Dried Fermented Spider Eye. This can be used with either a Happy Ghast or Strider for a temporary speed boost.

Consuming it when not riding a Happy Ghast or Strider will (lightly) posion the player.

## Requirements

Minecraft Java Edition 26.3

## Installation

Make sure to install as both a data and resource pack for proper functionality.

There are no non-standard requirements for this datapack, follow the normal steps in Minecraft or your launcher of choice to add it to your world.

## Uninstallation

There are no non-standard requirements for this data pack, it can be removed or disabled at any time.

Note: Make sure no Happy Ghasts are currently under the effect of this datapack before removing or they will be sped up indefinitely.
